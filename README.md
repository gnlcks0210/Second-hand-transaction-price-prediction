## 🚴 서울시 따릉이 대여 수요 예측 및 분석 프로젝트

서울시 공공자전거 '따릉이'의 대여소별 이용 데이터를 수집, 분석하여 대여 수요를 예측하고 최적 운영 방안을 도출하는 빅데이터 분석 프로젝트입니다.

---

## 1. 🎯 분석 목표 (Analysis Objectives)

본 프로젝트는 서울시 따릉이 대여 데이터를 기반으로 **대여 수요 패턴 분석 및 예측**을 목표로 합니다.

### 📈 시계열 트렌드 분석
2025년 상반기(1~6월) 동안 월별 대여량 변화를 분석하여 계절적 수요 패턴을 파악합니다.
- 겨울철(1~2월) vs 봄/여름철(3~6월) 수요 비교
- 월별 증감률 및 트렌드 시각화

### 🗺️ 공간적 패턴 분석
위도/경도 기반 K-Means 클러스터링을 통해 서울시를 8개 권역으로 분류하고, 지역별 대여 수요 특성을 분석합니다.
- 핫플레이스(고수요 지역) 식별
- 지역별 대여량 분포 차이 분석

### 🔄 대여-반납 불균형 분석
대여소별 대여건수와 반납건수를 비교하여 자전거 부족/과잉 현상을 파악하고, 재배치가 필요한 대여소를 도출합니다.

### 🤖 머신러닝 수요 예측
XGBoost 회귀 모델을 활용하여 대여소별, 월별 대여 수요를 예측합니다.
- 목표 성능: R² Score 0.85 이상
- 주요 예측 변수: 위치(cluster), 경도, 자치구, 시간(월)

## 3. 🛠️ 프로젝트 범위 및 기술 스택

### ⚙️ 프로젝트 파이프라인
```
1. 데이터 수집 (Data Collection)
   ↓
2. 데이터 전처리 (Preprocessing)
   ↓
3. 피처 엔지니어링 (Feature Engineering)
   ↓
4. 탐색적 데이터 분석 (EDA)
   ↓
5. 머신러닝 모델링 (Machine Learning)
   ↓
6. 결과 시각화 (Visualization)
```

#### 1️⃣ 데이터 수집
- 서울 열린데이터 광장에서 CSV 파일 다운로드
- 두 개의 데이터셋 로드 (이용정보 + 마스터 정보)

#### 2️⃣ 데이터 전처리
- 대여소명 기준으로 두 데이터셋 병합 (Inner Join)
- 텍스트 정제 (번호 제거, 공백 처리)
- 결측치 및 중복 데이터 제거
- 이상치 탐지 및 처리

#### 3️⃣ 피처 엔지니어링
- **시간 변수**: 기준년월 → 월(month) 추출
- **지역 변수**: 자치구 → Label Encoding
- **공간 클러스터링**: K-Means로 8개 지역 그룹 생성
- **계절 변수**: 여름 여부(is_summer) 생성

#### 4️⃣ 탐색적 데이터 분석 (EDA)
- 월별 대여량 추이 분석
- 자치구별/클러스터별 통계 분석
- 대여-반납 불균형 현황 파악
- 상관관계 분석

#### 5️⃣ 머신러닝 모델링
- 알고리즘: **XGBoost Regressor**
- 데이터 분할: Train 80% / Test 20%
- 하이퍼파라미터 튜닝
- 성능 지표: R² Score, MAE

#### 6️⃣ 결과 시각화
- 월별 트렌드 (Line Chart)
- 대여-반납 불균형 (Scatter Plot)
- 변수 중요도 (Bar Chart)
- 지역별 분포 (Box Plot)
- 핫플레이스 지도 (Folium Map)

## 4. 📊 예상 분석 결과 (Expected Outcomes)

> [!NOTE]
> 본 섹션은 프로젝트 수행 시 도출될 것으로 예상되는 분석 결과입니다.

### 📈 시계열 트렌드
- **예상**: 겨울철(1~2월) 저수요, 봄/여름철(3~6월) 고수요
- 3월부터 급격한 증가세 예상 (봄 날씨 영향)
- 6월에 최대 대여량 기록 예상

### 🗺️ 공간적 패턴
- **핫플레이스**: 한강공원, 강남역, 여의도 등 밀집 예상
- 클러스터별 수요 격차 발생 예상
- 외곽 지역은 상대적 저수요 예상

### 🔄 대여-반납 불균형
- 출근 시간대: 주거 지역 → 업무 지역으로 이동 예상
- 퇴근 시간대: 업무 지역 → 주거 지역으로 이동 예상
- 재배치가 필요한 대여소 리스트 도출 예상

### 🤖 예측 모델 성능
- **목표 R² Score**: 0.85 이상
- **핵심 변수**: cluster(지역), 경도, 자치구, 월
- 위치 기반 변수가 가장 높은 중요도를 가질 것으로 예상

### 🔑 핵심 인사이트 (예상)
1. **계절성**: 날씨가 대여 수요에 결정적 영향
2. **지역성**: 핫플레이스와 일반 지역 간 격차 큼
3. **불균형**: 시간대별 대여-반납 불일치로 재배치 필요
4. **예측 가능성**: 머신러닝으로 수요 예측 가능
